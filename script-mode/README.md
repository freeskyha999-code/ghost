# 剧本模式（Script Mode）

本目录用于存放独立的剧本模式/导演模式创作工具，和仓库根目录现有的 `index.html` 分开维护，避免覆盖原游戏。

## 计划内容

- 独立入口页面与剧本模式控制器
- 沉浸式第一人称模式与开发者上帝视角
- 方块背包、放置/拆除
- 生物、路径、台词、动作与仇恨机制
- 场景存档与 JSON 导入/导出
- 本目录专属的运行说明与资源清单

## 当前状态

目录已建立；完整工程文件、贴图和音效尚待导入与验证。未完成实际浏览器验收前，不应将此版本标记为已验证可玩。

默认只在本目录增加内容，不修改仓库根目录现有游戏，也不改动底层引擎；只有获得明确授权后才考虑修改原游戏或引擎。
